# 申万行业资金流看板 · API 接口文档

> 版本：v1.0　|　Base URL：`https://<host>/api/v1`　|　协议：HTTPS / JSON / UTF-8

## 1. 通用约定

### 1.1 统一响应结构

所有接口返回：

```json
{ "code": 0, "msg": "ok", "data": { }, "traceId": "a1b2c3d4" }
```

- `code = 0` 成功；非 0 为业务/系统错误。
- `data` 为具体业务数据，类型见各接口。
- `traceId` 用于排障，可回传运维定位日志。

### 1.2 错误码

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40001 | 参数缺失/格式错误 |
| 40101 | 未提供或非法的 `X-Api-Key` |
| 40102 | 未提供或非法的 `X-Admin-Key` |
| 40401 | 资源不存在（行业/股票代码不存在） |
| 42901 | 触发限流，请稍后重试 |
| 50301 | 数据未就绪（当日数据尚未采集） |
| 50000 | 服务器内部错误 |

### 1.3 单位与格式

| 项 | 约定 |
|----|------|
| 金额 | **亿元**，数值型，保留 4 位小数（如 `1.2345`） |
| 成交量 | **手**（1 手 = 100 股） |
| 日期 | `YYYY-MM-DD`；区间参数也接受 `YYYYMMDD` |
| 行业代码 | 申万代码，如 `801081`（二级）、`850131`（三级） |
| 股票代码 | `ts_code`，如 `600519.SH` |

### 1.4 鉴权

- 读接口：可选请求头 `X-Api-Key: <key>`（未开启时可不传）。
- 管理接口：必填请求头 `X-Admin-Key: <key>`。

### 1.5 分页

列表接口统一使用 `page`（默认 1）、`page_size`（默认 20，最大 100），响应：

```json
{ "code": 0, "msg": "ok", "data": { "list": [], "total": 0, "page": 1, "page_size": 20 } }
```

## 2. 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查 |
| GET | `/meta` | 数据范围与元信息 |
| GET | `/industries` | 行业列表（分页，可筛选/搜索） |
| GET | `/industries/tree` | 行业树（一/二/三级） |
| GET | `/industries/{sw_code}` | 行业详情 |
| GET | `/industries/{sw_code}/members` | 行业成分股（支持历史时点） |
| GET | `/industries/{sw_code}/flow` | 行业资金流时间序列 |
| GET | `/stocks/{ts_code}/flow` | 个股资金流时间序列 |
| GET | `/stocks/search` | 股票搜索 |
| POST | `/admin/fetch` | 手动触发采集（管理） |

## 3. 接口详情

### 3.1 健康检查

`GET /api/v1/health`

响应：

```json
{
  "code": 0, "msg": "ok",
  "data": { "status": "up", "db": "up", "latestTradeDate": "2026-09-21" }
}
```

### 3.2 元信息

`GET /api/v1/meta`

响应：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "dataStart": "2025-09-22",
    "dataEnd": "2026-09-21",
    "industryCount": { "l1": 31, "l2": 131, "l3": 336 },
    "stockCount": 5218,
    "generatedAt": "2026-09-21T17:40:00+08:00",

  }

```

### 3.3 行业列表

`GET /api/v1/industries?level=2&l1=电子&q=半&page=1&page_size=20`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| level | int | 否 | 行业级别 1/2/3，默认 2 |
| l1 | string | 否 | 一级行业名筛选 |
| q | string | 否 | 行业名/代码模糊搜索 |
| page / page_size | int | 否 | 分页 |

响应：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "list": [
      {
        "swCode": "801081", "name": "半导体", "level": 2,
        "l1Name": "电子", "memberCount": 181,
        "topStocks": ["德明利", "紫光国微", "大港股份", "康强电子"],
        "todayNet": 12.3456, "todayMain": 9.8765,
        "main5d": 45.678, "main10d": -8.9, "net5d": 50.12, "net10d": -3.4,
        "turnover": 180.23
      }
    ],
    "total": 131, "page": 1, "page_size": 20
  }
}
```

### 3.6 行业成分股

`GET /api/v1/industries/801081/members?as_of=2026-09-21&page=1&page_size=50`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| as_of | string | 否 | 历史时点 `YYYY-MM-DD`；缺省为最新 |

响应：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "asOf": "2026-09-21",
    "list": [
      { "tsCode": "000670.SZ", "name": "盈方微", "inDate": "2015-07-01", "outDate": null }
    ],
    "total": 181, "page": 1, "page_size": 50
  }
}
```

### 3.7 行业资金流

`GET /api/v1/industries/801081/flow?start=2026-09-01&end=2026-09-21`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start / end | string | 否 | 日期区间，缺省近 60 交易日 |

响应：

```json
{
  "code": 0, "msg": "ok",
  "data": {
    "swCode": "801081", "name": "半导体", "level": 2,
    "series": [
      {
        "d": "2026-09-21",
        "sm": -0.12, "md": 1.34, "lg": 2.10, "elg": 3.45,
        "main": 5.55, "net": 6.77,
        "cumMain": 20.11, "cumNet": 18.90,
        "turnover": 180.23, "memberCount": 181
      }
    ]
  }
}
```

字段说明：`sm/md/lg/elg` 为小/中/大/超大单净额（亿元）；`main = lg + elg`（主力）；`net` 为官方净流入；`cum*` 为区间累计；`turnover` 为成交额。

### 3.10 触发采集（管理）

`POST /api/v1/admin/fetch`

请求头：`X-Admin-Key: <key>`　|　请求体：

```json
{ "task": "all" }
```

`task` 可选：`all`（默认）｜`trade_cal`｜`stock_basic`｜`industry`｜`members`｜`moneyflow`｜`aggregate`。

响应：

```json
{ "code": 0, "msg": "ok", "data": { "task": "all", "status": "accepted", "startedAt": "2026-09-21T17:30:00+08:00" } }
```


## 6. 兼容性说明（与旧前端数据字段映射）

| 旧 mock 字段 | 新 API 字段 | 说明 |
|--------------|-------------|------|
| `f1`（今日净流入） | `todayNet` / `series[last].net` | 真实数据 |
| `f5 / f10` | `net5d / net10d` 或前端累加 | 真实数据 |
| `amt`（成交额） | `turnover` | 由 buy 侧求和 |
| `chg`（涨跌幅，mock 随机） | 需接入 `daily` 接口补充 | 见下方备注 |
| `pct`（强度） | 前端 `net/turnover` 计算 | — |

> 备注：涨跌幅（`chg`）不在 `moneyflow` 中，需新增 `daily`（日线）或 `daily_basic`（`pct_chg`）采集并增加 `GET /stocks/{ts_code}/daily` 接口；如客户不需要涨跌幅列，可先下线该列。
