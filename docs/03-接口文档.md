> 版本：v1.2　|　协议：HTTP / JSON / UTF-8
> **实际 Base URL**：`http://127.0.0.1:8000/api/v1`（当前为 uvicorn 直连，**无 HTTPS / 无 Nginx**）
> **文档性质**：v1.2 已按 `backend/app/main.py` **实际实现**核对，共 **13 个接口**。

## 1. 通用约定

### 1.1 统一响应结构

成功与业务错误均返回 HTTP 200，结构为：

```json
{ "code": 0, "msg": "ok", "data": { }, "traceId": "a1b2c3d4" }
```

- `code = 0` 成功；非 0 为业务/系统错误。
- `traceId`：本次请求随机 12 位十六进制，用于排障。
- ⚠️ **例外**：参数校验失败时 FastAPI 返回 **HTTP 422**，体为 `{"detail":[{"type":"...","loc":[...],"msg":"..."}]}`，不含 `code/msg`。前端需同时处理两种形态。

### 1.2 错误码（实际实现）

| code | HTTP | 含义 | 触发场景 |
|------|------|------|----------|
| 0 | 200 | 成功 | — |
| 40001 | 200 | 参数不合法 | `POST /admin/fetch` 传了未知 `task` |
| 40401 | 200 | 资源不存在 | 行业/股票代码不存在 |
| 40102 | 200 | 非法 `X-Admin-Key` | 管理接口 |
| 42901 | 200 | 采集任务已在运行 | `POST /admin/fetch` 并发触发 |
| 50000 | 500 | 服务器内部错误 | 未捕获异常 |
| —（422） | 422 | 参数校验失败 | FastAPI 原生，**非统一结构** |

> 未实现：`40101`（读接口鉴权）、`50301`（数据未就绪）；其余参数校验错误由 FastAPI 返回原生 422。

### 1.3 单位与格式

| 项 | 约定 |
|----|------|
| 金额 | **亿元**，数值型，保留 4 位小数（如 `1.2345`） |
| 成交量 | **手**（1 手 = 100 股，仅 `t_moneyflow` 原始表内，接口未暴露） |
| 日期 | 响应统一 `YYYY-MM-DD`；请求区间参数接受 `YYYY-MM-DD` 或 `YYYYMMDD` |
| 行业代码 | 申万代码，去 `.SI` 后缀，如 `801081`（二级）、`850131`（三级） |
| 股票代码 | `ts_code`，如 `600519.SH` |

### 1.4 鉴权（实际）

- **读接口：无鉴权**（`X-Api-Key` 未实现）。
- **管理接口**（`/admin/fetch`、`/admin/log`）：请求头 `X-Admin-Key: <key>`，与后端环境变量 `ADMIN_KEY` 比对。
- **fail closed**：若 `ADMIN_KEY` 未配置，或仍等于默认值 `change-me-admin-key`，管理接口**一律返回 `40102`**
  （后端不再回退到默认密钥；启动时会在控制台打印 `[WARN]`）。

### 1.5 分页（各接口上限不同）

统一参数 `page`（默认 1）、`page_size`，响应：

```json
{ "code": 0, "msg": "ok", "data": { "list": [], "total": 0, "page": 1, "page_size": 20 } }
```

| 接口 | page_size 默认 | 上限 |
|------|---------------|------|
| `/industries` | 20 | **1000** |
| `/industries/{code}/members` | 50 | 100 |
| `/stocks/search` | 10 | 100 |
| `/industries/{code}/stocks-flow` | 用 `limit`，默认 100 | 500 |

## 3. 接口详情

### 3.1 健康检查

`GET /api/v1/health`

```json
{ "code": 0, "msg": "ok",
  "data": { "status": "up", "db": "up", "latestTradeDate": "2026-09-24" } }
```

### 3.2 元信息

`GET /api/v1/meta`

```json
{ "code": 0, "msg": "ok",
  "data": {
    "dataStart": "2026-07-31",
    "dataEnd": "2026-09-24",
    "industryCount": { "l1": 31, "l2": 134, "l3": 346 },
    "stockCount": 5569,
    "generatedAt": null,
    "source": "tushare-compatible-proxy"
  } }
```

> `generatedAt` 当前恒为 `null`（未填充）；`dataStart/dataEnd` 取自 `t_moneyflow` 的日期范围。

### 3.3 行业列表

`GET /api/v1/industries?level=2&l1=电子&q=半&page=1&page_size=20`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| level | int | 否 | 1/2/3，默认 2 |
| l1 | string | 否 | 一级行业名精确匹配 |
| q | string | 否 | 行业名/代码模糊搜索 |
| page / page_size | int | 否 | 分页（page_size ≤ 1000） |

```json
{ "code": 0, "msg": "ok",
  "data": {
    "list": [
      {
        "swCode": "801081", "name": "半导体", "level": 2,
        "l1Name": "电子", "memberCount": 180,
        "topStocks": ["德明利", "紫光国微", "大港股份", "康强电子"],
        "todayNet": -136.1224, "todayMain": -92.5113,
        "main5d": 1.8069, "main10d": -41.509,
        "net5d": 2.34, "net10d": -30.12,
        "turnover": 2057.4007
      }
    ],
    "total": 134, "page": 1, "page_size": 20
  } }
```

> `todayNet` = 最新交易日官方净流入；`todayMain` = 最新交易日主力（大单+超大单）净流入；`main5d/main10d/net5d/net10d` = 最近 5/10 个交易日累计；`topStocks` 按代码序取前 4 只当前成分股。

### 3.4 行业树

`GET /api/v1/industries/tree`（无参数）

```json
{ "code": 0, "msg": "ok",
  "data": [
    {
      "swCode": "801080", "name": "电子", "level": 1, "parent_code": null,
      "l1_name": "电子", "memberCount": 0,
      "children": [
        {
          "swCode": "801081", "name": "半导体", "level": 2, "parent_code": "801080",
          "l1_name": "电子", "memberCount": 180,
          "children": [
            { "swCode": "850131", "name": "林业Ⅲ", "level": 3, "parent_code": "801011", "l1_name": "农林牧渔", "memberCount": 0, "children": [] }
          ]
        }
      ]
    }
  ] }
```

> 节点同时含有 `swCode` 与原始列 `sw_code`；`memberCount` 仅二级行业有值（当前只同步了二级成分股）。

### 3.5 行业详情

`GET /api/v1/industries/801081`

```json
{ "code": 0, "msg": "ok",
  "data": {
    "swCode": "801081", "name": "半导体", "level": 2,
    "l1Code": "801080", "l1Name": "电子",
    "memberCount": 180,
    "summary": {
      "todayNet": -136.1224, "net5d": -80.458, "net10d": -20.6631,
      "todayMain": -92.5113, "turnover": 2057.4007
    }
  } }
```

> `summary` 的 `net5d/net10d` 为最近 5/10 个交易日 `net` 之和。

### 3.6 行业成分股

`GET /api/v1/industries/801081/members?as_of=2026-09-24&page=1&page_size=50`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| as_of | string | 否 | 历史时点；**缺省 = 当前成分**（`out_date IS NULL`） |
| page / page_size | int | 否 | 分页（≤100） |

```json
{ "code": 0, "msg": "ok",
  "data": {
    "asOf": "2026-09-24",
    "list": [ { "tsCode": "001309.SZ", "name": "德明利", "inDate": "2024-07-31", "outDate": null } ],
    "total": 180, "page": 1, "page_size": 50
  } }
```

> 传入 `as_of` 时按 `in_date <= as_of AND (out_date IS NULL OR out_date > as_of)` 取时点成分；不传则返回当前成分，且 `asOf` 为 `null`。

### 3.7 行业资金流

`GET /api/v1/industries/801081/flow?start=2026-09-01&end=2026-09-24`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start / end | string | 否 | 日期区间；**缺省返回全部已有数据**（非"近 60 日"） |

```json
{ "code": 0, "msg": "ok",
  "data": {
    "swCode": "801081", "name": "半导体", "level": 2,
    "series": [
      { "d": "2026-09-24",
        "sm": 57.6218, "md": 34.8895, "lg": -20.7296, "elg": -71.7817,
        "main": -92.5113, "net": -136.1224,
        "turnover": 2057.4007, "memberCount": 180 }
    ]
  } }
```

字段：`sm/md/lg/elg` = 小/中/大/超大单净额（亿元）；`main = lg + elg`；`net` = 官方净流入；`turnover` = 成交额；累计值由前端计算（表内无 `cum_*` 列）。**仅二级行业有数据**。

### 3.8 个股资金流

`GET /api/v1/stocks/600519.SH/flow?start=2026-09-22&end=2026-09-24`

```json
{ "code": 0, "msg": "ok",
  "data": {
    "tsCode": "600519.SH", "name": "贵州茅台",
    "industry": "白酒Ⅱ", "industryCode": "801125",
    "series": [
      { "d": "2026-09-24", "sm": -0.003, "md": 5.1893, "lg": -2.8235,
        "elg": -2.3627, "main": -5.1862, "net": -4.8709, "turnover": 38.6805 }
    ]
  } }
```

> `turnover`（成交额，亿元）由买方侧四档求和得出。`industry/industryCode` 取该股当前所属**二级**行业，取不到时回退 `t_stock_basic.industry`。

### 3.9 股票搜索

`GET /api/v1/stocks/search?q=茅台&page=1&page_size=10`

```json
{ "code": 0, "msg": "ok",
  "data": {
    "list": [ { "tsCode": "600519.SH", "name": "贵州茅台", "industry": "白酒Ⅱ", "industryCode": "801125" } ],
    "total": 1, "page": 1, "page_size": 10
  } }
```

> `industry` 优先取当前所属二级行业名，取不到才回退 `t_stock_basic.industry`；`q` 必填（至少 1 字符）。

### 3.10 行业成分股区间资金流排行

`GET /api/v1/industries/801081/stocks-flow?start=2026-07-31&end=2026-09-24&limit=40`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start / end | string | 否 | 区间；缺省为全部已有数据 |
| limit | int | 否 | 返回条数，默认 100，上限 500 |

```json
{ "code": 0, "msg": "ok",
  "data": {
    "swCode": "801081",
    "list": [
      { "tsCode": "688012.SH", "name": "中微公司", "net": 46.0633, "main": 30.12, "turnover": 210.55 }
    ]
  } }
```

> 按区间 `net` 降序；成分按**时点成分**关联（`in_date <= trade_date < out_date/∞`）。当前仅二级行业有成分数据。

### 3.11 全市场二级行业强度

`GET /api/v1/strength`（无参数）

```json
{ "code": 0, "msg": "ok",
  "data": {
    "list": [
      { "swCode": "801012", "name": "农产品加工", "l1Name": "农林牧渔",
        "net": -12.34, "turnover": 380.5, "strength": -0.032116 }
    ]
  } }
```

> `strength = net / turnover`（区间净流入 ÷ 区间成交额），基于**全部已有数据**计算（非按天窗口）；`turnover=0` 时为 `null`。仅返回有聚合数据的二级行业。

### 3.12 触发采集（管理）

`POST /api/v1/admin/fetch`
请求头：`X-Admin-Key: <key>`（必填）　|　请求体：

```json
{ "task": "all" }
```

```json
{ "code": 0, "msg": "ok", "data": { "task": "all", "status": "accepted" } }
```

> 实现说明：`task` 取自 **JSON 请求体**，取值 `all`（默认）｜`meta`｜`members`｜`moneyflow`｜`aggregate`，
> 在后台线程执行 `etl.main([task])`；未知取值返回 `40001`；并发触发返回 `42901`；鉴权不通过返回 `40102`。
> 响应无 `startedAt`。**真实进度请用 `GET /admin/log`**。

### 3.13 采集日志（管理）

`GET /api/v1/admin/log?lines=200`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| lines | int | 否 | 返回尾部行数，默认 200，上限 2000 |

请求头：`X-Admin-Key: <key>`（必填）

```json
{ "code": 0, "msg": "ok",
  "data": {
    "exists": true,
    "total": 73,
    "mtime": "2026-09-29 23:35:52",
    "lines": ["[23:32:44] P0 ETL 启动 task=members …", "…", "[23:35:52] P0 ETL 完成（task=members）"]
  } }
```

> 读取后端 `cfg.log_file`（默认 `backend/etl_run.log`）尾部。管理页可据此展示**真实采集进度**
> （例如匹配末尾的「P0 ETL 完成」判定结束，或从 `P0 ETL 启动` 判定开始）。
> 注意：`etl.py` 每次启动会**清空重写**该日志，因此进度是「本次运行」的。

## 5. 前端接入示例

```js
// 前端已按此方式接入（API_BASE 在 file:// 下回退到 http://127.0.0.1:8000）

```

## 6. 与旧前端字段映射

| 旧 mock 字段 | 现接口字段 | 说明 |

## 7. 静态前端托管

FastAPI 通过 `StaticFiles` 挂载 `backend/static/` 到 `/`，可直接访问：

- `http://127.0.0.1:8000/fundflow.html`（资金流看板）
- `http://127.0.0.1:8000/industry.html`（行业分类浏览）
- `http://127.0.0.1:8000/index.html`（首页）

> `backend/static/` 是根目录前端文件的**副本**（为避免用静态服务暴露仓库内 `.env` 等敏感文件）；修改根目录 HTML 后需同步到 `static/` 才生效。
