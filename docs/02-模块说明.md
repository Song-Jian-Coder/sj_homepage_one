## 2. 模块职责

### 2.1 数据源适配器 `backend/tushare_client.py`

统一封装对数据源的访问，暴露 `call(api_name, **params) -> (rows, has_more)`。

- 请求体：`{"api_name", "token", "params", "max_rows": 6000}`，POST 到代理根路径
- 响应解析：`code` / `msg` / `data.fields` / `data.items` / `data.has_more`
- 内置能力（**实际**）：
  - **节流**：每次请求前保证间隔 ≥ `qps_delay`（默认 **0.25s/次 ⇒ ≤240 次/分钟**，低于接口 300 次/分钟 限制）
  - **限流退避**：`code=40203` 抛 `RateLimitError`，按 `rate_limit_wait × n`（15s/30s/45s/60s…）退避重试
  - **重试**：其它异常指数退避（1s/2s/4s…），默认最多 5 次
  - **分页**：返回 `has_more` 标志，**当前未续拉**（全市场单日 < 6000 行，实测 false）
  - **错误判定**：`code != 0` 抛 `DataSourceError`；`40203` 为其子类 `RateLimitError`

```python
class TushareClient:
    def __init__(self, endpoint, token, timeout=30, max_retries=3, qps_delay=0.15): ...
    def call(self, api_name, **params):
        payload = {"api_name": api_name, "token": self.token,
                   "params": params, "max_rows": 6000}
        for attempt in range(self.max_retries):
            try:
                r = self.session.post(self.endpoint, json=payload, timeout=self.timeout)
                r.raise_for_status()
                j = r.json()
                if j.get("code") != 0:
                    raise DataSourceError(f"{api_name}: code={j.get('code')} msg={j.get('msg')}")
                d = j.get("data") or {}
                rows = [dict(zip(d.get("fields") or [], it)) for it in (d.get("items") or [])]
                return rows, bool(d.get("has_more"))
            except Exception as e:
                if attempt == self.max_retries - 1:
                    raise
                time.sleep(2 ** attempt)
```

### 2.2 同步任务（`backend/etl.py` 内的函数）

| 函数 | 数据源 API | 目标表 | 策略 |
|------|-----------|--------|------|
| `sync_trade_cal` | `trade_cal` | `t_trade_cal` | 近 400 天，upsert |
| `sync_stock_basic` | `stock_basic` | `t_stock_basic` | 全量 5569 只，upsert |
| `sync_industry` | `index_classify`（L1/L2/L3） | `t_industry` | 全量 511 行，`industry_code` 建层级 |
| `sync_members` | `index_member` | `t_industry_member` | **L2(134) + L3(346)**；保留 `in_date/out_date`；源端空结果/失败分别计数，失败项二次重扫 |
| `sync_moneyflow` | `moneyflow` | `t_moneyflow` | 逐交易日**全市场**拉取（不按 ts_code 过滤成分股，过滤在聚合层做）；`MONEYFLOW_DAYS` 控制主窗口（`.env` 中为 242，代码默认 40；启动日志会打印生效值） |
| `aggregate_flow` | — | `t_industry_flow` | 读 `t_moneyflow` × 时点成分，按二级行业聚合 |

**核心口径**：

```
小单 net = buy_sm_amount  - sell_sm_amount
中单 net = buy_md_amount  - sell_md_amount
大单 net = buy_lg_amount  - sell_lg_amount
超大单 net = buy_elg_amount - sell_elg_amount
主力 main = 大单 + 超大单
官方净流入 net = net_mf_amount
成交额 turnover = buy_sm + buy_md + buy_lg + buy_elg（买方侧口径）
单位换算：万元 ÷ 10000 → 亿元（保留 4 位小数）
```

**时点成分**：交易日 T 的行业成分 = `in_date <= T AND (out_date IS NULL OR out_date > T)`，避免用「当前成分」回算历史造成幸存者偏差。

**幂等**：所有表按主键 `INSERT ... ON DUPLICATE KEY UPDATE`；按日/按行业分批 `commit`；失败仅记录并继续（不中断整批）。

## 3. 数据库设计（MySQL 8.0 / utf8mb4 / InnoDB）

### 3.1 ER 关系

```
t_industry(行业) 1──N t_industry_member(成分股，按 index_code) N──1 t_stock_basic(股票，按 con_code=ts_code)
       │
       1──N t_industry_flow(行业资金流聚合，按 sw_code)

t_stock_basic 1──N t_moneyflow(个股资金流，按 ts_code)
t_trade_cal / t_fetch_log  独立
```

### 3.2 建表 DDL（与 `backend/schema.sql` 完全一致）

```sql
CREATE DATABASE IF NOT EXISTS stock_data
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
USE stock_data;

-- 交易日历
CREATE TABLE IF NOT EXISTS t_trade_cal (
  cal_date      DATE        NOT NULL,
  exchange      VARCHAR(8)  NOT NULL,
  is_open       TINYINT     NOT NULL DEFAULT 1,
  pretrade_date DATE        NULL,
  PRIMARY KEY (cal_date, exchange)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 行业分类（一/二/三级统一，sw_code 去 .SI 后缀）
CREATE TABLE IF NOT EXISTS t_industry (
  id            BIGINT UNSIGNED AUTO_INCREMENT,
  sw_code       VARCHAR(16) NOT NULL,
  name          VARCHAR(64) NOT NULL,
  level         TINYINT     NOT NULL,
  parent_code   VARCHAR(16) NULL,      -- 上级 sw_code
  industry_code VARCHAR(16) NULL,      -- 申万原始 industry_code
  l1_name       VARCHAR(64) NULL,
  is_pub        CHAR(1)     NULL,
  updated_at    DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_sw_code (sw_code),
  KEY idx_parent (parent_code),
  KEY idx_level (level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 成分股（时点，index_code 去 .SI 后缀）
CREATE TABLE IF NOT EXISTS t_industry_member (
  id         BIGINT UNSIGNED AUTO_INCREMENT,
  index_code VARCHAR(16) NOT NULL,
  con_code   VARCHAR(16) NOT NULL,     -- 与 t_moneyflow.ts_code 同格式
  in_date    DATE        NULL,
  out_date   DATE        NULL,         -- NULL=当前仍在
  is_new     CHAR(1)     NULL,
  updated_at DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_member (index_code, con_code, in_date),
  KEY idx_con (con_code),
  KEY idx_out (out_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 股票基础信息
CREATE TABLE IF NOT EXISTS t_stock_basic (
  ts_code    VARCHAR(16) NOT NULL,
  symbol     VARCHAR(8)  NULL,
  name       VARCHAR(64) NULL,
  area       VARCHAR(32) NULL,
  industry   VARCHAR(64) NULL,
  market     VARCHAR(16) NULL,
  list_date  DATE        NULL,
  updated_at DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (ts_code),
  KEY idx_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 个股每日资金流（原始单位：万元 / 手）
CREATE TABLE IF NOT EXISTS t_moneyflow (
  ts_code         VARCHAR(16) NOT NULL,
  trade_date      DATE        NOT NULL,
  buy_sm_vol      DECIMAL(20,2) NULL,
  buy_sm_amount   DECIMAL(20,2) NULL,
  sell_sm_vol     DECIMAL(20,2) NULL,
  sell_sm_amount  DECIMAL(20,2) NULL,
  buy_md_vol      DECIMAL(20,2) NULL,
  buy_md_amount   DECIMAL(20,2) NULL,
  sell_md_vol     DECIMAL(20,2) NULL,
  sell_md_amount  DECIMAL(20,2) NULL,
  buy_lg_vol      DECIMAL(20,2) NULL,
  buy_lg_amount   DECIMAL(20,2) NULL,
  sell_lg_vol     DECIMAL(20,2) NULL,
  sell_lg_amount  DECIMAL(20,2) NULL,
  buy_elg_vol     DECIMAL(20,2) NULL,
  buy_elg_amount  DECIMAL(20,2) NULL,
  sell_elg_vol    DECIMAL(20,2) NULL,
  sell_elg_amount DECIMAL(20,2) NULL,
  net_mf_vol      DECIMAL(20,2) NULL,
  net_mf_amount   DECIMAL(20,2) NULL,
  updated_at      DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (ts_code, trade_date),
  KEY idx_date (trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 行业资金流聚合（亿元；注意：无 cum_* 列，累计值由接口/前端计算）
CREATE TABLE IF NOT EXISTS t_industry_flow (
  sw_code      VARCHAR(16) NOT NULL,
  level        TINYINT     NOT NULL,
  trade_date   DATE        NOT NULL,
  sm           DECIMAL(20,4) NULL,
  md           DECIMAL(20,4) NULL,
  lg           DECIMAL(20,4) NULL,
  elg          DECIMAL(20,4) NULL,
  main         DECIMAL(20,4) NULL,
  net          DECIMAL(20,4) NULL,
  turnover     DECIMAL(20,4) NULL,
  member_count INT         NULL,
  updated_at   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (sw_code, trade_date),
  KEY idx_date (trade_date),
  KEY idx_level_date (level, trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 采集审计日志（表已建，ETL 尚未写入——待补）
CREATE TABLE IF NOT EXISTS t_fetch_log (
  id           BIGINT UNSIGNED AUTO_INCREMENT,
  task_name    VARCHAR(64) NOT NULL,
  status       VARCHAR(16) NOT NULL,
  start_at     DATETIME    NULL,
  end_at       DATETIME    NULL,
  rows_fetched INT         NULL,
  rows_written INT         NULL,
  error_msg    TEXT        NULL,
  created_at   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_task (task_name, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
