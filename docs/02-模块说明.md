## 2. 模块职责

### 2.1 数据源适配器 `etl/tushare_client.py`

统一封装对数据源的访问，**屏蔽「代理 / 官方 Tushare」差异**，暴露 `call(api_name, **params) -> list[dict]`。

- 请求体：`{"api_name", "token", "params", "max_rows"}`
- 响应解析：`code/msg/data.fields/data.items/data.has_more`
- 内置能力：
  - **重试**：网络异常/限流 429/5xx 指数退避（如 1s/2s/4s，最多 3 次）
  - **限流**：令牌桶控制 QPS（默认 ≤ 5 次/秒，可配）
  - **分页**：`has_more=true` 时续拉直到取全（避免 `max_rows` 截断丢数据）
  - **字段校验**：断言关键字段存在，异常抛出明确错误
- 关键实现要点（伪代码）：

```python
class TushareClient:
    def __init__(self, endpoint, token, timeout=30, max_retries=3, qps=5):
        ...
    def call(self, api_name, **params):
        payload = {"api_name": api_name, "token": self.token,
                   "params": params, "max_rows": 6000}
        for attempt in range(self.max_retries):
            try:
                r = self.session.post(self.endpoint, json=payload, timeout=self.timeout)
                r.raise_for_status()
                j = r.json()
                if j.get("code") != 0:
                    raise DataSourceError(f"{api_name}: {j.get('msg')}")
                rows = self._items_to_dicts(j["data"]["fields"], j["data"]["items"])
                # 分页兜底：has_more 为真时续拉
                return rows
            except (Timeout, ConnectionError, DataSourceError) as e:
                if attempt == self.max_retries - 1:
                    raise
                time.sleep(2 ** attempt)
```

### 2.2 同步任务（ETL）

| 模块 | 数据源 API | 目标表 | 策略 |
|------|-----------|--------|------|
| `sync_trade_cal` | `trade_cal` | `t_trade_cal` | 增量，按日期区间 |
| `sync_stock_basic` | `stock_basic` | `t_stock_basic` | 全量/增量，upsert |
| `sync_industry` | `index_classify`（或内置映射） | `t_industry` | 全量，`parent_code` 建层级 |
| `sync_members` | `index_member` | `t_industry_member` | 全量，保留 `in_date/out_date` |
| `sync_moneyflow` | `moneyflow` | `t_moneyflow` | 逐交易日增量，按成分股 `ts_code` 过滤 |
| `aggregate_flow` | — | `t_industry_flow` | 读 `t_moneyflow` 按行业聚合 |

**核心口径（与前端一致）**：

```
小单 net = buy_sm_amount  - sell_sm_amount
中单 net = buy_md_amount  - sell_md_amount
大单 net = buy_lg_amount  - sell_lg_amount
超大单 net = buy_elg_amount - sell_elg_amount
主力 net = 大单 + 超大单
官方净流入 = net_mf_amount
成交额     = buy_sm+md+lg+elg（买方口径，近似）
单位换算：万元 ÷ 10000 → 亿元（保留 4 位小数）
```

**时点成分（修正历史口径）**：某交易日 T 的行业成分 = 满足 `in_date <= T 且 (out_date IS NULL 或 out_date > T)` 的股票。避免用「当前成分」回算历史导致幸存者偏差。

**幂等与增量**：所有表用 `(主键)` upsert（`INSERT ... ON DUPLICATE KEY UPDATE`）；采集结果先写临时表/事务，成功后提交；失败回滚并在 `t_fetch_log` 记录。

### 2.3 服务层（FastAPI）

| 模块 | 职责 |
|------|------|
| `routers/` | 路由与参数校验，不写 SQL |
| `services/` | 业务查询：行业树、资金流序列、搜索、聚合 |
| `models/` + `db.py` | ORM 与连接池（`pool_size`/`max_overflow` 合理配置） |
| `schemas/` | 请求/响应 Pydantic 模型，统一字段与单位 |

## 3. 数据库设计（MySQL 8.0 / utf8mb4 / InnoDB）

### 3.1 ER 关系

```
t_industry (行业) 1──N t_industry_member (成分股) N──1 t_stock_basic (股票)
       │
       1──N t_industry_flow (行业资金流聚合)

t_stock_basic 1──N t_moneyflow (个股资金流)
t_trade_cal   (独立交易日历)
t_fetch_log   (独立审计)
```

### 3.2 建表 DDL

```sql
CREATE DATABASE IF NOT EXISTS stock_data
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;

-- 交易日历
CREATE TABLE t_trade_cal (
  cal_date      DATE        NOT NULL,
  exchange      VARCHAR(8)  NOT NULL,
  is_open       TINYINT     NOT NULL DEFAULT 1,
  pretrade_date DATE        NULL,
  PRIMARY KEY (cal_date, exchange)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 行业分类（一/二/三级统一）
CREATE TABLE t_industry (
  id           BIGINT UNSIGNED AUTO_INCREMENT,
  sw_code      VARCHAR(16) NOT NULL,          -- 801080 / 801081 / 850131
  name         VARCHAR(64) NOT NULL,
  level        TINYINT     NOT NULL,          -- 1/2/3
  parent_code  VARCHAR(16) NULL,              -- 上级行业代码
  l1_code      VARCHAR(16) NULL,
  l1_name      VARCHAR(64) NULL,
  member_count INT         NULL,
  updated_at   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_sw_code (sw_code),
  KEY idx_parent (parent_code),
  KEY idx_level (level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 成分股（时点，含历史调入调出）
CREATE TABLE t_industry_member (
  id         BIGINT UNSIGNED AUTO_INCREMENT,
  index_code VARCHAR(16) NOT NULL,            -- 801081.SI
  con_code   VARCHAR(16) NOT NULL,            -- 000670.SZ
  stock_name VARCHAR(64) NULL,
  in_date    DATE        NULL,
  out_date   DATE        NULL,                -- NULL=当前仍在
  is_new     CHAR(1)     NULL,                -- Y/N
  updated_at DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_member (index_code, con_code, in_date),
  KEY idx_con (con_code),
  KEY idx_out (out_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 股票基础信息
CREATE TABLE t_stock_basic (
  ts_code    VARCHAR(16) NOT NULL,
  symbol     VARCHAR(8)  NULL,
  name       VARCHAR(64) NULL,
  area       VARCHAR(32) NULL,
  industry   VARCHAR(64) NULL,
  market     VARCHAR(16) NULL,
  list_date  DATE        NULL,
  updated_at DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (ts_code),
  KEY idx_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 个股每日资金流（原始单位：万元 / 手）
CREATE TABLE t_moneyflow (
  ts_code         VARCHAR(16) NOT NULL,
  trade_date      DATE        NOT NULL,
  buy_sm_vol      DECIMAL(20,2) NULL,
  buy_sm_amount   DECIMAL(20,2) NULL,
  sell_sm_vol     DECIMAL(20,2) NULL,
  sell_sm_amount  DECIMAL(20,2) NULL,
  buy_md_vol      DECIMAL(20,2) NULL,
  buy_md_amount   DECIMAL(20,2) NULL,
  sell_md_vol     DECIMAL(20,2) NULL,
  sell_md_amount  DECIMAL(20,2) NULL,
  buy_lg_vol      DECIMAL(20,2) NULL,
  buy_lg_amount   DECIMAL(20,2) NULL,
  sell_lg_vol     DECIMAL(20,2) NULL,
  sell_lg_amount  DECIMAL(20,2) NULL,
  buy_elg_vol     DECIMAL(20,2) NULL,
  buy_elg_amount  DECIMAL(20,2) NULL,
  sell_elg_vol    DECIMAL(20,2) NULL,
  sell_elg_amount DECIMAL(20,2) NULL,
  net_mf_vol      DECIMAL(20,2) NULL,
  net_mf_amount   DECIMAL(20,2) NULL,
  updated_at      DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (ts_code, trade_date),
  KEY idx_date (trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 行业资金流聚合（亿元，预计算，加速查询）
CREATE TABLE t_industry_flow (
  sw_code      VARCHAR(16) NOT NULL,
  level        TINYINT     NOT NULL,
  trade_date   DATE        NOT NULL,
  sm           DECIMAL(20,4) NULL,   -- 小单净额(亿)
  md           DECIMAL(20,4) NULL,
  lg           DECIMAL(20,4) NULL,
  elg          DECIMAL(20,4) NULL,
  main         DECIMAL(20,4) NULL,   -- 主力 = lg + elg
  net          DECIMAL(20,4) NULL,   -- 官方净流入
  cum_main     DECIMAL(20,4) NULL,
  cum_net      DECIMAL(20,4) NULL,
  turnover     DECIMAL(20,4) NULL,   -- 成交额(亿)
  member_count INT         NULL,
  updated_at   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (sw_code, trade_date),
  KEY idx_date (trade_date),
  KEY idx_level_date (level, trade_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 采集审计日志
CREATE TABLE t_fetch_log (
  id           BIGINT UNSIGNED AUTO_INCREMENT,
  task_name    VARCHAR(64) NOT NULL,
  status       VARCHAR(16) NOT NULL,        -- running/success/failed
  start_at     DATETIME    NULL,
  end_at       DATETIME    NULL,
  rows_fetched INT         NULL,
  rows_written INT         NULL,
  error_msg    TEXT        NULL,
  created_at   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_task (task_name, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.3 数据库账号（最小权限）

```sql
-- 采集账号（读写）
CREATE USER 'stock_etl'@'%' IDENTIFIED BY '<从.env读取>';
GRANT SELECT, INSERT, UPDATE, DELETE ON stock_data.* TO 'stock_etl'@'%';

-- 接口账号（只读）
CREATE USER 'stock_read'@'%' IDENTIFIED BY '<从.env读取>';
GRANT SELECT ON stock_data.* TO 'stock_read'@'%';
```
